AAC Practical Assignments - Set 2 (C)

Files:
AAC2_Q1.c - Fractional Knapsack (Greedy)
AAC2_Q2.c - Topological Sort (Kahn's Algorithm)
AAC2_Q3.c - Floyd-Warshall (All-Pairs Shortest Paths)
AAC2_Q4.c - N-Queens (Backtracking)
AAC2_Q5.c - Prim's Minimum Spanning Tree
AAC2_Q6.c - Strassen's Matrix Multiplication
AAC2_Q7.c - 0/1 Knapsack (Dynamic Programming)
AAC2_Q8.c - Dijkstra's Shortest Paths

Compile using GCC:
gcc AAC2_Q1.c -o AAC2_Q1
Run:
./AAC2_Q1

On Windows, run the generated executable AAC2_Q1.exe.
The programs use standard input prompts. Vertices in graph programs are numbered from 0.
For Floyd-Warshall, use 1000000000 to represent no edge in the input matrix.
For Prim and Dijkstra, 0 represents no edge between distinct vertices.
